# Naman Rugs & Carpets — Unhurried Craft, Bhadohi

> **A Milanese Editorial Digital Flagship & 3D Interactive WebGL Platform for India’s Premier Handcrafted Rug Enterprise.**  
> *Handmade in Bhadohi • Est. 1999 • Founder & Studio Principal: Naman Dubey*

---

## 🏛️ Digital Architecture Overview

Rooted in Bhadohi, Uttar Pradesh (India’s legendary carpet capital), **Naman Rugs & Carpets** elevates centuries of authentic Indian handcraft into high-fashion Milanese editorial design (inspired by *cc-tapis*, *Nanimarquina*, and *Jaipur Rugs*). 

This platform delivers an ultra-responsive, dynamic 3D web experience tailored for global interior designers, hospitality specifiers, and discerning residential collectors.

---

## ✨ Key Features & Architectural Capabilities

### 1. 🧵 Real-Time 3D WebGL Rug Configurator (`/custom-studio`)
- **Procedural PBR Rug Textures**: Custom yarn normal, bump, roughness, and displacement generation across **Hand-Knotted (Heirloom)**, **Hand-Tufted (Sculpted Relief)**, and **Flatweave Dhurries**.
- **Interactive Staging**: Switch dynamically between `Overhead (90°)`, `Room Staging (45°)`, and `1:1 Macro Knot` inspection.
- **Dynamic Lighting Rig**: Realistic grazing angle sunlight and cast shadow simulation showing wool & silk pile luster.
- **Dimensional Customizer**: Real-time recalculation of knot density, square footage, lead times, and multi-currency pricing (`INR`, `USD`, `EUR`, `GBP`, `AED`).
- **One-Click Spec PDF & WhatsApp Export**: Instant transmission of CAD dimensions to Bhadohi loom masters.

### 2. 💬 Omnipresent WhatsApp Atelier Concierge
- **Floating Concierge Widget**: Live indicator dot with instant access to Naman Dubey and Bhadohi studio specifiers.
- **Direct Specifier Hotlines**: Embedded throughout the header, PDP customizer, trade portal, and footer.
- **One-Click Inquiries**: Pre-filled templates for Custom Dimensions, Loom Video Tours, Physical Yarn Swatch Boxes, and B2B Trade quotes.

### 3. 🗺️ Dedicated Subpage Routing System
- **`/collections`**: Faceted filtering by Weaving Technique, Room Placement, Color Palette, and Shape with multi-column layout switches.
- **`/custom-studio`**: Bespoke 3D WebGL configurator with real-time cloth drape and knot inspection.
- **`/size-guide`**: Interactive 1:25 scale CAD architectural diagrams (*All Legs On*, *Front Legs Only*) and room placement rules.
- **`/manchaha`**: Social empowerment gallery celebrating weaver-designed rugs with 100% artisan royalties.
- **`/services`**: Care, fiber chemistry, emergency stain triage, and restorative Bhadohi river wash booking.
- **`/trade`**: Dedicated portal for architects, interior designers, and hospitality specifiers with tiered volume pricing.
- **`/about`**: 25-year heritage dossier detailing the 8 loom stages (Sorting, Carding, Spinning, Dyeing, Weaving, Washing, Embossing, Finishing).
- **`/contact`**: Factory (Maryadpatti) and Carpet City showroom coordinates with interactive appointment bookings.

### 4. 🛍️ Milanese Editorial E-Commerce Suite
- **Interactive Search Modal**: Live keyword search across catalog names, techniques, and fiber compositions.
- **Curated Wishlist Drawer**: LocalStorage-persisted collection with quick 3D inspection.
- **Heirloom Loom Bag**: Custom dimension checkout bag with currency conversions and white-glove shipping calculators.
- **Single-Line Zero-Wrap Navigation**: Clean, unhurried typography disciplined by modern design tokens.

## 🛠️ Technology Stack

- **Framework**: React 18, TypeScript
- **Styling**: Tailwind CSS, PostCSS (Tailwind typography & custom HSL color tokens)
- **3D & Animation**: Three.js, Lucide Icons, Canvas 2D Procedural Texture Engine
- **Routing**: React Router DOM (v7) with automatic scroll restoration
- **Build Tooling**: Vite 8 with HMR

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/codemonk33/my-project.git
cd my-project

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will be running locally at `http://localhost:5173/`.

### Production Build
```bash
npm run build
```
